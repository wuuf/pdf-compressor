PDF-Compressor

PDF-Dateien einfach und offline verkleinern – direkt auf deinem Gerät, ohne dass deine Dokumente es je verlassen.

100 % Offline Datenschutz-sicher Kostenlos & Open Source
Auf GitHub ansehen Datenschutzerklärung

Für Android. Auf Deutsch und Englisch.

Was die App kann

Komplett offline

Die App hat keinen Internetzugriff. Deine PDFs werden ausschließlich auf deinem Gerät verarbeitet.

Keine Daten, kein Tracking

Kein Konto, keine Werbung, keine Analyse, keine Absturzberichte. Es werden keine Daten erhoben.

Auch große Scans

Seiten werden einzeln verarbeitet. So lassen sich auch PDFs mit Hunderten Megabyte verkleinern.

Nie größer als vorher

Bringt das Verkleinern nichts, behält die App dein Original unverändert und sagt dir das.

Speichern oder teilen

Das Ergebnis speicherst du, wo du willst, oder teilst es direkt per Mail, Messenger und Co.

Open Source

Der Quellcode ist unter der Apache License 2.0 frei einsehbar.

So funktioniert's

  1. PDF auswählen – über die Dateiauswahl deines Geräts.
  2. Stärke wählen – Leicht, Empfohlen oder Stark.
  3. Verkleinern – und das Ergebnis speichern oder teilen.

Kompressionsstufen

StufeAuflösungGeeignet für
Leicht150 DPIHohe Qualität, z. B. zum Ausdrucken
Empfohlen110 DPIGute Balance aus Qualität und Größe
Stark72 DPIKleinste Datei, z. B. für E-Mail-Anhänge

Hinweis: Die App wandelt jede Seite in ein Bild um. Text in der verkleinerten PDF lässt sich danach nicht mehr markieren oder durchsuchen.
