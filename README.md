# PDF-Compressor

Einfach und 100% offline PDF-Dateien unter Android verkleinern.

## Features
* **100% Offline & Datenschutz-sicher:** Alle Berechnungen finden lokal auf dem Gerät statt.
* **3 Kompressionsstufen:** Leicht (150 DPI), Empfohlen (110 DPI) und Stark (72 DPI).
* **Direktes Speichern & Teilen:** Speichern im Downloads-Ordner oder direktes Versenden.
